# Kairos Advisory Group Website

A modern, professional website for Kairos Advisory Group built with Astro and Tailwind CSS.

## 🚀 Live Site

Visit the live site: [https://jraftcreative.github.io/kairos-website](https://jraftcreative.github.io/kairos-website)

## 🛠 Tech Stack

- **Framework:** [Astro](https://astro.build) v5.x
- **Styling:** [Tailwind CSS](https://tailwindcss.com) v4.x
- **Hosting:** GitHub Pages
- **Deployment:** GitHub Actions

## 📁 Project Structure

```
/
├── public/              # Static assets (favicons, images)
├── src/
│   ├── components/      # Reusable UI components
│   ├── layouts/         # Page layouts
│   ├── pages/           # Route pages
│   │   ├── services/    # Service pages
│   │   └── ...
│   └── styles/          # Global styles
├── .github/workflows/   # CI/CD configuration
└── astro.config.mjs     # Astro configuration
```

## 🧞 Commands

| Command           | Action                                       |
|:------------------|:---------------------------------------------|
| `npm install`     | Install dependencies                         |
| `npm run dev`     | Start local dev server at `localhost:4321`   |
| `npm run build`   | Build production site to `./dist/`           |
| `npm run preview` | Preview build locally before deploying       |

## 📝 Pages

- **Home** (`/`) - Hero, approach, services overview, CTA
- **About** (`/about`) - Company story and values
- **Our Approach** (`/approach`) - Six-step planning process
- **Services** (`/services`) - Full service offerings
- **Team** (`/team`) - Meet the advisers
- **Career** (`/career`) - Join the team
- **Contact** (`/contact`) - Contact form and info

## 🚀 Deployment

The site automatically deploys to GitHub Pages when pushing to the `main` branch via GitHub Actions.
